## Agent skills

### Issue tracker

Issues live as GitHub issues on `Bakar-se/portfolio-by-bakar`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five roles mapped to plain-language labels: `needs-review`, `needs-details`, `agent-ready`, `needs-a-person`, `wont-do`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
